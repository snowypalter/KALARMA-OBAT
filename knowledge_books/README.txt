FOLDER SUMBER BUKU REFERENSI CHATBOT RUANG OBAT
==============================================

Cara menambahkan sumber buku (.zip) ke Chatbot:
1. Letakkan file arsip `.zip` (atau `.pdf`, `.txt`, `.md`) berisi buku/pedoman farmasi ke dalam folder ini (`knowledge_books/`), lalu klik tombol "Muat Ulang Folder" di panel Sumber Buku pada Chatbot (atau restart server).
2. Atau langsung unggah file `.zip` melalui tombol "Unggah .zip Buku" di dalam jendela Chatbot pada aplikasi web.

Format file di dalam `.zip` yang didukung otomatis:
- Dokumen PDF (`.pdf`)
- Teks polos (`.txt`)
- Markdown (`.md`)
- Data terstruktur (`.json`, `.csv`)
- Halaman HTML (`.html`, `.htm`)
